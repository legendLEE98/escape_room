# Escape the Room 문서 안내

이 폴더에는 현재 게임을 만들 때 필요한 기준 문서를 정리해 둔다.

## 먼저 읽기

처음 프로젝트를 확인할 때는 이 순서로 읽으면 된다.

1. [게임 플레이](./GAMEPLAY.md)
   - 플레이어가 게임을 어떻게 시작하고, 무엇을 하며, 어떻게 탈출하는지 정리한 문서다.
2. [아키텍처](./ARCHITECTURE.md)
   - 프론트엔드, Three.js, 서버, nginx, Docker가 어떤 역할을 맡는지 정리한 문서다.
3. [DB와 JSON 구조](./DATABASE_AND_JSON.md)
   - 맵, 방, 오브젝트, 상호작용 데이터를 어디에 어떤 모습으로 저장하는지 정리한 문서다.

## 문서별 사용 시점

| 상황 | 먼저 볼 문서 |
| --- | --- |
| 게임 규칙이나 화면 흐름을 정할 때 | 게임 플레이 |
| 프론트엔드, 서버, 배포 작업을 할 때 | 아키텍처 |
| 테이블을 수정하거나 맵 저장 기능을 만들 때 | DB와 JSON 구조 |

## 현재 상태

- 쿼터뷰 이동과 GLB 캐릭터 표시가 구현되어 있다.
- 맵 에디터에서 GLB 에셋을 배치할 수 있다.
- 프론트엔드는 React + Vite + Three.js를 사용한다.
- PostgreSQL은 Docker 컨테이너로 실행 중이다.
- 맵 저장 API, 게임방, 멀티플레이는 아직 구현 전이다.
