# 게임 플레이

## 이 문서를 볼 때

게임의 화면 흐름, 퍼즐 방식, 아이템과 문 해금 규칙을 정할 때 본다. 테이블과 저장 형식은 [DB와 JSON 구조](./DATABASE_AND_JSON.md), 화면과 서버 구성은 [아키텍처](./ARCHITECTURE.md)를 참고한다.

## 게임 한 판의 흐름

```text
맵 목록
  → 게임방 생성 또는 참가
  → 인원 확인
  → 게임 시작
  → 3D 맵 탐색
  → 오브젝트 상호작용
  → 2D 모달에서 퍼즐 진행
  → 아이템 획득 또는 문 해금
  → 탈출 성공 또는 시간 초과
```

## 3D 맵과 2D 모달의 역할

3D 맵에서는 캐릭터를 움직이고, 방을 찾고, 상호작용할 오브젝트를 발견한다.

오브젝트를 클릭하면 같은 화면 위에 2D 모달이 열린다. 퍼즐과 상세 조작은 이 모달 안에서 진행한다. 모달이 열려 있는 동안에는 캐릭터 이동과 카메라 조작을 막는다.

```text
3D 맵에서 서랍 클릭
  → 화면 어두워짐
  → 서랍 2D 이미지와 입력창이 있는 모달 표시
  → 비밀번호 성공
  → 열쇠 획득
  → 모달 닫힘
  → 3D 맵 탐색 계속
```

## 상호작용 예시

| 대상 | 모달에서 하는 일 | 결과 |
| --- | --- | --- |
| 서랍 | 비밀번호 입력 | 열쇠 획득 |
| 액자 | 이미지 확대와 단서 확인 | 숫자 단서 확인 |
| 금고 | 숫자 조합 맞추기 | 다음 아이템 획득 |
| 문 | 열쇠 보유 여부 확인 | 다음 방 이동 가능 |

## 모달 규칙

- 배경의 3D 화면은 남겨 두고 어둡게 보이게 한다.
- 모달 내부의 버튼, 이미지, 입력칸만 조작할 수 있다.
- 닫기 버튼과 `ESC` 키로 닫을 수 있다.
- 성공하면 아이템, 문 상태, 퍼즐 진행 상태를 게임방에 기록한다.
- 모달을 닫는다고 실패 처리하지는 않는다.

## 게임방 상태

맵 원본은 바꾸지 않는다. 플레이 중 바뀌는 정보는 게임방마다 따로 가진다.

- 현재 참여자
- 현재 방
- 획득한 아이템
- 열린 문
- 푼 퍼즐
- 시작 시간과 남은 시간

이 정보는 나중에 게임 세션 테이블과 실시간 서버에서 관리한다.
